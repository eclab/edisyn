Sequential Fourm

Patch editor and librarian for the Sequential Fourm synthesizer.

Banks

The Fourm has 4 banks of 128 patches each:

  • U1 – User Bank 1 (writable)
  • U2 – User Bank 2 (writable)
  • F1 – Factory Bank 1 (read-only)
  • F2 – Factory Bank 2 (read-only)

Tabs

  • Global – Patch name, category, scale, transpose, clock, pitch bend
  • Oscillators – Osc 1 and 2 waveforms, mix, feedback, noise, glide
  • Filter – Cutoff, resonance, key tracking, filter envelope
  • Envelope + LFO – Amp envelope and LFO parameters
  • Modulation – Mod source routing and destination assignments
  • Arp / Voice – Arpeggiator, sequencer controls, unison, key mode
  • Seq 1 – Seq 4 – Step editor for each sequencer track (64 steps each)

Sequencer

Each of the four sequencer tracks has its own tab. Scroll vertically to access all 64 steps. Per step: note (displayed as note name), velocity, and Rest/Tie/Glide checkboxes.

Notes on Display Values

Most parameter names and ranges have been verified against a 512-patch hardware dump and the official Fourm User Guide. A few are still unconfirmed and may show an inaccurate label or an "Off"-mapped value if your patch uses them:

  • Key Mode – this parameter's meaning and option names aren't documented anywhere we could find; the current label guesses may be wrong
  • Noise Type – a 4th value exists beyond the three documented types (White/Pink/Violet)
  • Clock Div – some patches use values beyond the 11 divisions either Sequential document lists, possibly added in a firmware update

SysEx

  • Manufacturer ID: 0x01 (Sequential)
  • Device ID: 0x3B (Fourm)
  • Program Dump: F0 01 3B 02 <bank> <prog> <4690 packed bytes> F7
  • Edit Buffer: F0 01 3B 03 <4690 packed bytes> F7

MIDI SysEx must be enabled in the Fourm's globals (SysX = On, SysX Port = USB or MIDI).
