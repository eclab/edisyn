Novation Bass Station II

Single Patch Editor

This patch editor should work with any Bass Station II with at least v4.14 firmware, though it might work with earlier versions.

Sending and Receiving Individual Parameters

At present Edisyn does not send nor receive individual parameters: the Bass Station II can only receive a subset of the parameters, and it does so through a tangle of CC and NRPN messages with arbitrary ranges. You can set Edisyn to automatically send the entire patch to current memory after a bit after you have changed a parameter. To do this, check both "Sends Real Time Changes" and "Auto-Sends Patches" under the "MIDI" menu.

Perhaps later Edisyn will support at least receiving real-time parameter changes.

Bass Station Sysex Protocol

Novation did not open their protocol, so it had to be reverse engineered. Furthermore, the protocol is a mess, with highly inconsistent parameter ranges and settings throughout. This made reverse engineering fun. My reverse engineered spec is at the end of the NovationBassStation2.java in Edisyn's code repository. It is based in part on work by Francois Georgy (francois.georgy@gmail.com) but has extensive revisions, bug fixes, and extensions. You should use it rather than his version (presently available at https://github.com/francoisgeorgy/BS2-SysEx).

Display Notes

  • Retrigger Count only appears when you turn on Retrigger. Its lowest value, marked "0" on the synth, actually is "Infinity" and Edisyn displays it as such.

  • Changing Filter Type will change the number of filter options displayed.

  • When the Sub Osc Coarse and Fine are both set to zero, the synth will instead lock the Suboscillator to the tuning of Oscillator 1.

  • The patch name is not displayed on the synth.
